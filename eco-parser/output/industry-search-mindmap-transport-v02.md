# MIRLEX | Отраслевая рекламная mindmap: поисковые запросы v0.2

2026-10-08. Пилот **IND-001–005**, 50 поисковых формулировок-гипотез, 15 рекламных заголовков-гипотез. Источники: ECO PARSER / отраслевые вопросы; редакционная адаптация процессов и проблем. **Без РОП.** Экорадар, ядро, Tilda не изменяются.

**Метод:** конкретная отрасль → технология / материальный поток → проблема человека → разговорная формулировка поискового запроса → предложение экологической диагностики → заголовок. «Похожие запросы» широкого Wordstat не используем как доказательство спроса. Общие запросы вроде «мойка» исключаем. Статусы: `OBSERVED_MANUAL` — пользователь сообщил частотность из Wordstat; `HYPOTHESIS` — частотность не измерена, не считать её нулём.

## Проверка перед рекламой

- Сначала ручная и экспертная фильтрация релевантности; всё, что только похоже на спрос, остаётся гипотезой.
- Не суммировать вложенные частоты, не считать общую частоту показателем готовности купить услугу.
- В Директе минус-фразы использовать только после анализа поисковых фраз конкретной кампании; широкие минус-слова могут отсечь качественный спрос.
- Каждую рекламную гипотезу связывать с реально оказываемой услугой, а не с обещанием автоматической обязательности документов.
- Расширять по оставшимся 53 отраслевым ID с тем же сохранением различий технологических проблем.
