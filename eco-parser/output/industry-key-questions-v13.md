# MIRLEX | Ключевые вопросы для 58 отраслей — v1.3

Дата: 08.10.2026. **58 отраслей × 3 уникальных диагностических вопроса**. Источник имён: `eco-parser/seeds/industries.json`; источники структуры: MIRLEX Engine ECO_EXPERT, внутренние карты v0.3–v1.2. Эти вопросы — **редакторская исследовательская подборка**, не машинно утверждённые 58 отраслевых rulepacks Engine. Для автомоек есть внутренний отраслевой seed Engine, для других — универсальные контуры.

**Граница:** никакого РОП, расчёта экосбора, товаров/упаковки. РОП вызывается только как отдельный MIRLEX-эксперт.

**Цель:** первый контакт, выявление фактов и предварительная маршрутизация без бесплатной юридической экспертизы. Вопросы не подразумевают наличие нарушения и не устанавливают обязанность.

**Использование:** один отраслевой блок на странице, не нужно отображать в нём все вопросы. При CTA сохранить `industry_id` и показать три вопроса для соответствующей отрасли; четвёртый общий вопрос — «Что сейчас нужно: разобраться с документами / проверить действующие / оформить новые / подготовиться к проверке / другое». Юридические ветки запускает ядро на основании ответов.
