## Отраслевое применение рекламной mindmap

1. Сохраняем 10 групп и 58 постоянных ID в ECO PARSER.
2. Для отрасли включаем только релевантные ветки — пример: IND-001 «Автомойки» → вода и стоки; IND-025 «Мебель» → пыль/аспирация; IND-037 «Гальваника» → стоки и шламы.
3. Не создаём 58 кампаний заранее. Проверяем 3–4 рекламных направления услуг и масштабируем по реальным качественным заявкам.
4. После запуска сайта Метрика фиксирует industry_id и тему обращения. Данные не объявляем имеющимися до установки и проверки целей.

## Безопасность и точность

Текст объявлений должен соответствовать фактической услуге и посадочной странице; не утверждать нарушения, штрафы, обязательность документов без проверки исходных условий. НВОС-категории определяются по фактическим критериям, не по названию отрасли. РОП — полностью отдельно.

## Техническое состояние статистики

Репозиторий: eco-parser/output/status.json = WAITING_FOR_WORDSTAT_CREDENTIALS. У действующего скрипта Yandex Search API требуются платные ресурсы, автоматической бесплатной статистики в текущем workflow нет. Возможность CSV выгрузки из веб-интерфейса есть, но без авторизованной сессии не является автоматическим парсером. Снимать защиту сайта или использовать неофициальные обходы не предлагается.
